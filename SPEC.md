# Análisis Transaccional - Juego Educativo

## Descripción
Juego de preguntas tipo test para aprender los fundamentos del Análisis Transaccional (AT).

## Niveles
- **Principiante**: Conceptos básicos (Estados del Yo, transacciones)
- **Medio**: Tipos de transacciones, juegos psicológicos
- **Avanzado**: Scripts de vida, arqueología existencial, aplicaciones clínicas

## Requisitos técnicos
- Single HTML con CSS y JS embebido
- Diseño limpio y accesible
- 5 preguntas por nivel
- Feedback inmediato con explicación
- Pantalla de resultados finales

## Contenido mínimo
- Preguntas sobre: Padre, Adulto, Niño (PAC)
- Transacciones complementarias vs cruzadas
- Juegos psicológicos básicos (Triángulo de Karpman)
- Estados del Yo según Eric Berne
